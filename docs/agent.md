# Правила параллельной разработки VIctory-NVIDIA

Общее руководство для ChatGPT, Antigravity, Codex CLI и Claude.

## Публикация изменений

- Публикуй каждый законченный логический патч сразу в общей рабочей ветке, не ожидая окончания всех тестов и бенчмарков.
- Перед публикацией проверь изменения и актуальный удалённый SHA. Не перезаписывай чужой код: только fast-forward, без force push.
- Указывай в коммите и комментариях PR #1, какие проверки пройдены, какие ещё не запускались, какие ошибки известны.
- Не выдавай непроверенный патч за стабильную сборку. Рискованные экспериментальные режимы оставляй выключенными по умолчанию.
- Не блокируй остальные задачи ожиданием одной длительной проверки. При подтверждённом зависании заверши только проблемный процесс, сохрани лог и опубликуй промежуточный результат.
- Для сборок, тестов, бенчмарков и git push применяй разумные тайм-ауты; не повторяй уже пройденные проверки того же SHA без причины.

## Координация

- Используй существующие ветки main, dev/nvidia-blackwell и cto/shader-hash-perf. Не создавай дополнительные ветки, worktree или PR без необходимости и согласования.
- Общий PR: https://github.com/ai2n-dev/VIctory-NVIDIA/pull/1.
- ChatGPT: архитектура, GPU, VRAM, CARD_COMPARE и Readback. Antigravity: локальные сборки, аппаратная проверка и исправления совместимости. Codex/Claude: многопоточность и аудит памяти.
- Перед работой проверь изменения других агентов. Не редактируй одновременно одни и те же локальные файлы. Не перезаписывай незакоммиченные изменения.
- Сохраняй авторство и лицензии стороннего кода. Соблюдай docs/asset-policy.md, не публикуй секреты или локальные данные.
- Не объединяй экспериментальную ветку с main до подтверждения сборки и тестов.

Результаты: SHA, проверенный адаптер, тесты, бенчмарки, известные ошибки и следующие шаги. Публикуй по мере готовности, а не одним отчётом в конце.
